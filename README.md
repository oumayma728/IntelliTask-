# Smart Task Manager

A **full-stack task management application** built to practice real-world development, testing, and deployment.

It includes a **Kanban board, calendar with Google Calendar sync, a chatbot, and user settings**, with a focus on maintainability, testing, and containerization.

## 🛠 Tech Stack

- **Frontend:** React  
- **Backend:** .NET  
- **Database:** SQL Server  
- **Testing:** Unit & integration tests, E2E with Cypress  
- **CI/CD:** GitHub Actions  
- **Deployment:** Docker & Docker Compose  

---

## ⚡ Features

- Kanban board for task management  
- Calendar with Google Calendar integration  
- Chatbot via API  
- User settings and task configuration  
- Full containerization (frontend, backend, database)  
- Automated testing with GitHub Actions
